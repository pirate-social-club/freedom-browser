# Checkpoint notice capture

These source-only tools retain original helper notices and checksum-bound
source records. They have an explicit --apply mode and never build, install
or execute the target helpers. Local captures use the task's conservative
CPU, memory and no-swap envelope.

Notice capture is not a blanket shipping verdict. Bee's embedded
github.com/ethersphere/batch-archive v0.0.8 has no recovered explicit license
declaration for its wrapper or snapshot. Its repository's import instructions
do not establish a redistribution grant. Do not assign Bee's BSD terms to
that separate module without supporting evidence.

The checkpoint omits the bundled Bee binary, configuration and notices rather
than substituting a grant for that component. No outside request was posted.

The conservative Radicle lock graphs include archives without standalone
notice files. Those crates do declare explicit licenses. The supplemental
recovery retains their declarations, original source attribution, matching
project notices and full text for a selected offered license. Both platform
and test entries remain included conservatively; no source reconstruction or
blanket shipping verdict follows from metadata alone. The supplemental output
requires independent notice review before packaging.

Independent review cleared the new hnsd/HNS import and the supplemental
notice scope, including the matching original Radicle MIT notices at all
three embedded revisions. This permits the scoped hosted evaluation build;
no reproducible rebuild of unchanged release binaries or installed acceptance
is claimed by that review. Actual package and installed proofs remain required.
